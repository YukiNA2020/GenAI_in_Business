# 标签推荐 Prompt

负责人：成员 E / 成员 5  
阶段：阶段一 - 任务 3  
用途：根据用户输入生成 3-8 个标签，帮助用户整理收藏。

---

## 1. 目标

生成适合收藏记录的短标签，帮助用户后续搜索、筛选和回忆。

要求：

1. 生成 3-8 个标签。
2. 标签要短，建议 2-6 个中文字符。
3. 标签之间不能重复。
4. 不要太泛，例如避免只输出“收藏”“物品”“记录”。
5. 尽量包含地点、类别、情绪或主题。
6. 只输出稳定 JSON。

---

## 2. 输入字段

```json
{
  "title": "东京蓝色明信片",
  "category": "明信片",
  "location": "东京",
  "description": "在一家小书店买到的蓝色明信片，想留作旅行记忆"
}
```

| 字段 | 类型 | 是否必填 | 说明 |
|---|---|---|---|
| `title` | string | 否 | 收藏标题 |
| `category` | string | 否 | 收藏类别 |
| `location` | string | 否 | 收藏获得地点 |
| `description` | string | 是 | 收藏描述 |

---

## 3. Prompt 模板

```text
你是 Collection Journey App 的收藏标签助手。请根据用户提供的信息，为这件收藏品生成 3 到 8 个中文标签。

标签规则：
1. 每个标签要短，建议 2 到 6 个中文字符。
2. 标签不能重复。
3. 不要输出过于泛化的标签，例如“收藏”“物品”“记录”。
4. 尽量包含地点、类别、情绪、主题或使用场景。
5. 如果信息不足，也要返回至少 3 个保守标签。
6. 只输出 JSON，不要输出 Markdown 或解释文字。

用户输入：
- 标题：{{title}}
- 类别：{{category}}
- 地点：{{location}}
- 描述：{{description}}

请严格按照以下 JSON 格式输出：
{
  "tags": ["东京", "明信片", "旅行", "书店"]
}
```

---

## 4. 输出格式

```json
{
  "tags": ["东京", "明信片", "旅行", "书店"]
}
```

---

## 5. 异常处理建议

当输入很少时：

```json
{
  "tags": ["个人记忆", "小物件", "日常收藏"]
}
```
