# 分类建议 Prompt

负责人：成员 E / 成员 5  
阶段：阶段一 - 任务 2  
用途：根据用户输入和可选图片描述，推荐最合适的收藏类别。

---

## 1. 目标

根据用户输入的标题、描述、地点和图片描述，从默认类别中选择一个最合适的收藏类别，并给出置信度。

默认类别：

1. 矿石
2. 水晶
3. 黑胶唱片
4. 明信片
5. 票根
6. 旅行纪念品
7. 其他

---

## 2. 输入字段

```json
{
  "title": "东京蓝色明信片",
  "description": "在一家小书店买到的蓝色明信片",
  "location": "东京",
  "imageDescription": "一张蓝色调的城市风景明信片"
}
```

| 字段 | 类型 | 是否必填 | 说明 |
|---|---|---|---|
| `title` | string | 否 | 用户已输入或 AI 生成的标题 |
| `description` | string | 是 | 用户输入的收藏描述 |
| `location` | string | 否 | 收藏获得地点 |
| `imageDescription` | string | 否 | 图片识别或用户补充的图片描述 |

---

## 3. Prompt 模板

```text
你是 Collection Journey App 的收藏分类助手。请根据用户输入，从固定类别列表中选择一个最合适的类别。

固定类别只能是：
["矿石", "水晶", "黑胶唱片", "明信片", "票根", "旅行纪念品", "其他"]

分类规则：
1. category 必须严格来自固定类别列表。
2. confidence 是 0 到 1 之间的小数，表示你对分类的信心。
3. 如果信息不足或无法判断，请选择 "其他"，confidence 不要高于 0.5。
4. 不要输出固定类别以外的名称。
5. 只输出 JSON，不要输出 Markdown 或解释文字。

用户输入：
- 标题：{{title}}
- 描述：{{description}}
- 地点：{{location}}
- 图片描述：{{imageDescription}}

请严格按照以下 JSON 格式输出：
{
  "category": "明信片",
  "confidence": 0.82
}
```

---

## 4. 输出格式

```json
{
  "category": "明信片",
  "confidence": 0.82
}
```

---

## 5. 异常处理建议

当输入模糊时：

```json
{
  "category": "其他",
  "confidence": 0.45
}
```
