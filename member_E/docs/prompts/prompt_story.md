# 故事生成 Prompt

负责人：成员 E / 成员 5  
阶段：阶段一 - 任务 4  
用途：根据用户输入生成 100-150 字的收藏故事草稿。

---

## 1. 目标

生成一段温暖、可编辑、适合作为个人记忆记录的收藏故事草稿。

要求：

1. 字数控制在 100-150 个中文字符左右。
2. 语气温暖，但不要夸张。
3. 不编造用户没有提供的具体事实。
4. 可以围绕用户已提供的类别、地点、日期和描述做轻微润色。
5. 输出必须是稳定 JSON。

---

## 2. 输入字段

```json
{
  "title": "东京蓝色明信片",
  "category": "明信片",
  "location": "东京",
  "dateAcquired": "2026-05-01",
  "description": "在一家小书店买到的蓝色明信片，想留作旅行记忆"
}
```

| 字段 | 类型 | 是否必填 | 说明 |
|---|---|---|---|
| `title` | string | 否 | 收藏标题 |
| `category` | string | 否 | 收藏类别 |
| `location` | string | 否 | 收藏获得地点 |
| `dateAcquired` | string | 否 | 收藏获得日期 |
| `description` | string | 是 | 用户原始描述 |

---

## 3. Prompt 模板

```text
你是 Collection Journey App 的收藏故事助手。请根据用户提供的信息，生成一段 100 到 150 个中文字符左右的收藏故事草稿。

写作规则：
1. 语气温暖、自然，有个人记忆感。
2. 不要编造用户没有提供的具体事实、人物、品牌或事件。
3. 如果信息不足，请围绕“保存这件收藏的意义”写得更保守。
4. 文本应方便用户继续编辑，不要写成广告文案。
5. 只输出 JSON，不要输出 Markdown 或解释文字。

用户输入：
- 标题：{{title}}
- 类别：{{category}}
- 地点：{{location}}
- 日期：{{dateAcquired}}
- 描述：{{description}}

请严格按照以下 JSON 格式输出：
{
  "story": "生成的故事文本"
}
```

---

## 4. 输出格式

```json
{
  "story": "这张蓝色明信片是在东京一家小书店买到的。它不算昂贵，却像是把那天的街道、光线和慢慢挑选的心情一起留了下来。以后再看到它时，也许会想起那段安静而轻盈的旅行时间。"
}
```

---

## 5. 异常处理建议

当输入很少时：

```json
{
  "story": "这件小小的收藏被保存下来，不只是因为它本身特别，也因为它承载了当时的一点心情。即使细节以后会慢慢变模糊，它仍然能提醒我：那一刻曾经真实地发生过。"
}
```
